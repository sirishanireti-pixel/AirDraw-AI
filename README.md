# 🎨 AirDraw AI
Real-time touchless air drawing using webcam hand tracking and MediaPipe Hands.

🌐 Live Website: https://airdraw-siri.web.app/

AirDraw AI is a real-time webcam-based air drawing application that allows users to draw on a digital canvas by moving their index finger in the air — without touching the screen.

## 🚀 Features

* Real-time hand tracking using MediaPipe Hands
* Index finger tracking using landmark 8
* Air drawing using hand gestures
* Fist/open palm for drawing pause
* Thumb + index finger pinch to clear the canvas
* Mirrored webcam feed for natural movement
* Real-time hand skeleton overlay
* Fingertip cursor
* Multiple brush colors
* Multiple brush sizes
* Adjustable brush opacity
* Eraser mode
* Smooth line rendering
* Neon/glow drawing effects
* Particle trail effects
* Undo and redo
* Gesture-based controls
* FPS and hand-confidence display
* Stroke counter
* Save drawing as PNG
* Keyboard shortcuts
* Responsive dark UI
* Runs completely in the browser
* No backend required

## ✋ Gesture Controls

| Gesture                | Action        |
| ---------------------- | ------------- |
| ☝️ Index finger raised | Draw          |
| ✊ Fist                 | Pause drawing |
| 🖐️ Open palm          | Pause drawing |
| 🤏 Thumb + index pinch | Clear canvas  |
| ✌️ Peace sign          | Change color  |
| 🤙 Call-me gesture     | Undo          |

## ▶️ How to Run

### Option 1 — Open locally

Download or clone the repository and open `index.html` in Google Chrome.

Allow webcam permission when prompted.

> If the browser blocks webcam access when opening the file directly using `file://`, run the project through a local web server such as VS Code Live Server.

### Option 2 — Firebase Hosting

The application can also be hosted using Firebase Hosting.

## 🔒 Privacy

Hand tracking and drawing processing are performed in the browser. The application does not require a custom backend for drawing functionality.

## 🎯 Project Objective

The goal of AirDraw AI is to demonstrate how computer vision and browser technologies can be combined to create a touchless human-computer interaction system.
